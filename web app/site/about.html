About the Project

About Astro Hub

An educational astronomy platform built to make learning about space fun and accessible.

Introduction

Astro Hub is a modern, responsive web application created for students and space enthusiasts. It brings together information about the planets, historic space missions, a gallery of cosmic imagery and an interactive quiz — all inside a clean, space-themed interface. The project is designed as a beginner-friendly frontend built with only HTML, CSS, JavaScript and Bootstrap.

Objectives

  • Make astronomy education engaging and interactive.
  • Provide easy-to-understand facts about our Solar System.
  • Showcase famous NASA and ISRO space missions.
  • Encourage learning through quizzes and exploration.

Features

  • Planet Explorer with detailed planet pages.
  • 19+ space mission cards with details.
  • Searchable, filterable NASA image gallery.
  • 20-question interactive quiz with scoring.
  • Favorites system to save what you love.

Technology Stack

HTML5 CSS3 JavaScript Bootstrap 5 Font Awesome

Future Scope

  • Live NASA API integration for real-time imagery.
  • Implement Augmented Reality (AR) features for interactive exploration of planets and celestial objects.
  • 3D interactive Solar System model.
  • Add real-time tracking of satellites, the International Space Station (ISS) .
